# 方法备忘：ABM 接 LLM agent 时怎么设对照（草稿，2026-11-28）

状态：只是备忘。`post-scarcity-abm-llm` 按 RESEARCH_AGENDA 仍暂停（等 Stage 2 有真实系数）；这份只写"万一重启，实验该怎么设"，不改任何代码，不改第一篇。

## 三篇依据（都只核了 arXiv 摘要页，正文没读）

1. 🟢 **交流过的 agent 不是独立样本。** 同模型"克隆" agent 互相交流后，连和话题无关的 BFI-10 人格问卷都漂移，温度为 0 重测仍在；作者结论是"每个互相交流的群体只算一个重复"，把 agent 当独立样本需要配对的不交流对照。（Zheng, Luo & Luu, arXiv:2611.29581，2026-11-22 预印本）
2. 🟢 **同一配置重复跑大体可复现，但 prompt/记忆一换就挪。** 同一世界、同一起点跑 10 遍（共 700 小时），多数网络和个体参数跨重复稳定；把一个 agent 的人设 prompt 或积累的记忆移植给别人，接收者"大约 60%"地往供体性格靠，下一轮就开始像供体。（Alisch 等, arXiv:2611.31543，2026-11-23 预印本）
3. 🟢 **prompt 细节不写清，别人复现不了。** ODD 协议加五个 LLM 专用文档块（基于 CoALA）；漏掉"你是旁观者不是玩家"这一句，收敛到约定的比例从 0.35 变 1.00、快三倍；回看 28 篇已发表 LLM-agent 模拟，77% 的 prompt 构造和输出解析写不清。（Downes, Milletich & Hirst, arXiv:2611.08932，2026-11-09 预印本）

## 对我们的设计含义 🟡（我的推论，未检验）

- **统计单位是"一次运行"，不是"一个 agent"。** 现有 ABM 里每个 agent 的意义感是独立抽样算误差的；换成 LLM agent 后，同一次运行里的几百个 agent 只算一个样本。功效计算要按运行次数做，跑的次数会比现在多很多。
- **每个条件配一组"不交流"对照。** 同样的人设、同样的冲击（如失业），但 agent 之间不发消息，只各自记日记。比较"交流 vs 不交流"的差，才知道意义感变化里有多少是社会传染、多少是 LLM 本身漂移。
- **prompt 当成参数，不当成常量。** 对人设、系统提示各做 2–3 个可辩护的变体（ODD+LLM 的"多宇宙"思路）；结论只有在变体间都成立才写。
- **记忆是处理变量。** 既然移植记忆能挪 60%，"有无长期记忆"要单独做一个因子，不能默认开着。
- **文档按 ODD+LLM 写。** 每次调用的完整 prompt、模型版本、温度、输出解析规则都进仓库，JASSS 审稿也看这个。

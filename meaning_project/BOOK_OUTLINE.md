# BOOK OUTLINE — 论证弧线（指南针，非容器）
# Working title (TBD): *When the Work Is Gone* / 《当工作消失之后》

> **这是什么 / What this is.** 这本书的**论证弧线骨架**。它是 `SYNTHESIS.md`（按子问题生长
> 的知识库 / 疆域）的**指南针**：它从知识库里抽取一条线、排成有起承转合的旅程，并指出弧线
> 需要、而知识库还缺的地方。**书不是容器**——它不把所有 Q 都塞进来，只取它需要的那条线。
> 知识库会长得比书大得多。
>
> **关系 / Relationship.**
> - 书的弧线**指出缺口** → 去研究/写文章填 → 成果进知识库 → 知识库某处成熟 → 反哺书的某章。
> - 双向，但**书牵引知识库的生长方向**。每章末尾标注它依赖知识库的哪些 Q、以及哪些 Q 还没熟到
>   能支撑这一章（= 待补的研究/写作）。
>
> **性格 / Character（已定）.**
> - **建设型 + 个人安慰与指引** 的叠加。不贩卖恐慌，不给虚假确定。承认未来不可知，然后双层
>   回答：①社会/制度层"能稳健准备什么"；②个人/心理层"作为一个具体的人，你能怎么活、意义从
>   哪来"。
> - **双螺旋结构**：每一章都既问"社会能怎么办"（🔴稳健设计为主），又问"你个人能怎么办"
>   （🟢有证据的安慰 + 坦诚标注的🔴良言）。
> - **具体入口 / 普世归宿**：以"焦虑的专业人士"（程序员、设计师、写作者——正亲眼看着 AI 进入
>   饭碗的人）为入口，通向"任何思考意义的人"的普世命题：*当产出不再定义你，你是谁？* 专业
>   人士只是最先撞墙的人，他们的处境是全人类的预演。
>
> **诚实护栏（关乎本书护城河）.** 对个人的每一句安慰/指引都标明层级：🟢 有数据的安慰（如退休
> 研究）vs 🔴 坦白的价值建议（"我建议你培养一项不靠产出定义的连接性活动"——承认是建议，不
> 假装是科学）。这让本书的安慰比任何励志书可信——因为它诚实区分"有证据的"和"我的良言"。
>
> **状态：** 🌱 弧线草案 v0.2。九章双语已成稿（见 `book/chapters/` 与 `book/chapters_zh/`）；
> 本骨架仍是指南针，已据实际章节同步过第6/7章标题与论证。

## 弧线总览 / The arc in one breath

立靶（你担心错了方向）→ 揭示工作偷偷给了你什么 → 证明钱补不上那个洞 → 追问这次是否真的不一样
→ 直视社会失去工作会怎样 → 转向：还能往哪退（社会与个人的出口）→ 收束：一种诚实地活在不确定
里的方式。

情绪线不是"惊吓→焦虑→鸡汤"，而是**"被看见 → 被诚实告知 → 被给予方向"**。读者旅程：从切身的
职业焦虑，走到对自身意义来源的重新理解，最后拿到一套可以据以行动的、诚实的指引。

## 序章 / Prologue — 错误的问题
**钩子（具体入口）：** 每个人都在问"AI 会不会抢走我的工作"。但一个程序员的真实故事（可用 SO
研究：一整个靠"解答问题"获得胜任与地位的社群，在 ChatGPT 之后真实地萎缩了）揭示：就算你保住
收入，*真正在流失的是别的东西*。
**立靶（普世化的第一步）：** 真问题不是"会不会失业"，而是——**就算给了你钱，你的人生还剩
什么？**（经济–意义解耦，一上来就立。）
**本书承诺：** 不吓你，不哄你。诚实地分三层告诉你我们知道什么、能推断什么、只能选择什么；
并在每一步同时回答"社会能怎么办"和"你个人能怎么办"。
**挂 SYNTHESIS：** §0 元问题（经济–意义解耦）；🔬 so_sdt_study 作开场实例。

## 第一部 · 我们低估了工作 / What work was secretly doing

### 第1章 工作偷偷给了你什么
**论证推进：** 揭示工作 = 收入 + 一整套意义功能（时间结构、社会接触、集体目标、身份地位、被
需要）。读者第一次意识到自己低估了它。
**社会层：** 现代社会把"工作"建成了意义的默认分发系统。
**个人层（安慰/指引）：** 🟢 如果你最近隐隐失落却说不清，这不是矫情——失去的是可命名的东西。
先把它命名出来，是自救的第一步。
**挂：** Q1（工作的潜功能🟢）。

### 第2章 钱补不上那个洞
**论证推进：** 把"大不了发钱"这个集体安慰剂打碎。UBI/退休/彩票的真实证据：钱买 relief，不买
meaning。→ 逼出问题：那个洞靠什么补？
**社会层：** UBI 是地板，不是意义引擎。把它当终点是危险的误判。
**个人层（安慰/指引）：** 🟢 如果你在等"财务自由"那天让你完整——温柔的坏消息：你要的东西钱
买不到；🟢 好消息：它也不必靠钱，它在别处，后面带你找。
**挂：** Q2（钱vs意义🟢）、Q4（有钱无工作者🟢）。**承重柱章——证据最强。**

---

## 第二部 · 这次不一样吗 / Is this time different?

### 第3章 你是不是在瞎担心？
**论证推进：** 直面读者最想问的类比——AI 像不像工业革命。给出诚实的🟡：骨架像，但三个变量
可能断裂（自动化的是判断本身/速度/"新岗位"前提）。
**社会层：** 把空泛的乐观/悲观，换成三个可追踪的仪表盘变量。
**个人层（安慰/指引）：** 🔴 不假装能预测你的职业会不会消失；但教你盯哪三个信号，自己判断
自己的处境——把不可知变成可观察。
**挂：** Q5（工业革命类比🟡）、Q6（已发生的劳动影响🟢）。

### 第4章 最先撞墙的人（具体→普世的枢纽）
**论证推进：** 谁先受冲击。专业人士（你）是最先撞墙的——但这正是全人类的预演。AI 把每个人
迟早都变成"提前退休的人""中彩票的人"——那些我们已有真实数据的群体。
**枢纽作用：** 这一章把"具体入口"翻转为"普世归宿"——你的焦虑不是小众职业问题，是人类共同
命题的先声。
**两个已显现的"早期实验室"（🟢 真实数据，本章的实证锚）：**
- **Stack Overflow**：一个自愿、无合同黏性的知识社区，AI 一来就被不受缓冲地掏空——贡献活动
  2026 已降 ~95%。它预演的正是"当你的产出可被即时替代、又没人付薪留你时会怎样"。本项目自己
  的 SO 研究（🔬 so_sdt_study）就站在这个实验室里。
- **职业阶梯底端（22–25岁入门岗）**：2026 唯一可测的白领信号，而它恰好砸在"工作型身份/地位
  通常被建立"的那一级——意义上最危险的地方。
**为何 SO 比白领整体更早撞墙（推理，🟡）：** 有合同的工作有黏性缓冲，自愿贡献没有——这是
"先行者"论证的机制假设。**2026-05 直接检验（RT-04B / contract_buffer_study）得出预注册零
结果**：CPS 内同职业的无合同 vs 受薪者，AI 暴露梯度上的差异在统计上与零无法区分（β₃≈−2.2%/SD,
p=0.21；安慰剂同号同量级）。正文已据此把"先行者"明确降为"被零结果投下阴影的、有理据的忧虑"，
并承认 SO 崩塌更可能是"高可替代特例"。
**个人层：** 🟢 你不是孤例，也不是最惨；你是先行者（即便降级后）——你有时间准备。
**挂：** Q10（谁先受冲击🟡）、Q6（已发生的劳动影响🟢）、Q4（有钱无工作者作为"全人类预演"
的镜子）。自有实证：so_sdt_study（🟢 SO 崩塌测量；零结果于行为代理）+ contract_buffer_study
（🟢 预注册 null 于合同黏性机制）+ platform_trend。

## 第三部 · 当社会失去工作 / When society loses work（最暗的一部）

### 第5章 会崩坏到什么程度？
**论证推进：** 直视黑暗面但拒绝危言耸听：行为沉沦隐喻（诚实批判其适用性）、绝望之死（🟢 最硬
旁证）、地位竞争的迁移。
**诚实护栏：** 明确区分🟢（绝望之死是真实死亡率数据）与🟡/🔴（行为沉沦多是推断、隐喻易被
误用）。
**社会层：** 失去工作角色的社会风险是真实的，但其形态高度依赖制度反应。
**个人层（安慰）：** 🟢 黑暗有真实成分，但"崩坏"不是命定的——它取决于可改变的因素，这本身
是希望的来源。
**挂：** Q8（行为沉沦🟡❓）、Q9（地位竞争🔴🟡）。

## 第四部 · 还能往哪退 / Where we can still go（转向出口）

### 第6章 重新找到你的位置 / Finding Your Place Again（全书目的地）
**论证推进：** 从诊断转向行动。核心是命名并展示一个动作：从**结果锚定**（意义系在钱/地位/认可
等不由你控制的外部结果上）转向**过程锚定**（意义系在去做、学习、就在你面前的人这些你能控制和
体验之物上）。用作者自己用 AI 做游戏的真实故事贯穿——AI 既是杠杆（让"不会"变"会"）、也是
护城河摧毁者（这根杠杆人人都有），所以把意义压在产出结果上是越来越糟的赌注。
**社会层：** （留待第7章）。
**个人层（指引）：** 🟢 SDT/内在 vs 外在目标证据（Niemiec/Ryan/Deci 2009 等，达成外在目标
不提升幸福）+ 🟢 关切的话出自人比出自 AI 更被感到有共情（9 实验 >6000 人）。**坦白限制：**
本章假设读者有余裕重新定向；对生计骤断、账单到期者，这是奢侈——把人交给第7章。
**挂：** Q7（抗 AI 的意义源🟡）、Q3（虚拟能否替代🟡）、SDT 文献🟢。

### 第7章 政策能做的 / What Policy Can Do（放大利益、降低伤害）
**论证推进：** 框架不是"对抗 AI"，而是**stewardship**——"放大 AI 给公民带来的利益；降低它
伤害公民的可能性与严重程度"。读者不是行动者，是看天气的水手。
**社会层（🔴 设计章）：** 降低伤害（地板/UBI、为速度做缓冲、再培训的诚实账与"雇主挂钩"例外、
分配收益：Yang $2.8-3T 账 + Alaska 油气分红先例 + $142B/季 capex 政治算术）+ 放大利益
（普及杠杆门槛、保护人与人彼此被需要的空间）。方法论：RDM/Robust Decision Making（Lempert
/RAND）——稳健赌注，非预测。
**个人层：** 把本章当背景读，理解你正在适应*进入*的环境。安静的交接回第6章：政策越好，越多人
够得着那个从结果锚定到过程锚定的转身。
**挂：** Q11（稳健策略🔴+ RDM 方法论🟢）、Q12（政策杠杆🟡🔴）。

## 终章 / Epilogue — 诚实地活在不确定里
**收束（不是答案，是姿态）：** 我们无法预测这场变革的终点。但"无法预测"不等于"无法准备"。
给读者两样东西带走：
- **一套思考工具**：三层框架——分清你知道的、能推断的、要选择的。让你今后面对任何 AI 预测
  都不被忽悠。
- **一种生活姿态**：把意义从"产出/职业"上松绑，重新锚定在连接、手艺、被需要、当下——不是
  因为这是鸡汤，而是因为证据和审慎的推理都指向这里。
**普世归宿落地：** 当产出不再定义你——你依然是你，而且也许更是你。
**个人层收尾（最后的安慰）：** 🟢+🔴 诚实地说清哪些是数据给的安慰、哪些是我的良言；正因为
分清了，它才值得信。
**挂：** §0 元问题、Q13（生命阶段/代际🔴🟡）、全书回扣三层框架。

# 研究事项汇总 / Research agenda for the book

书稿写作中浮现的、需要深挖或做研究才能从 🟡/🔴 推向 🟢（或确认其层级）的事项。
这是我们**一起讨论**的清单。优先级：⭐⭐⭐ 高（决定核心论证可信度）/ ⭐⭐ 中 / ⭐ 低（润色级）。

类型：**核实** = 已有线索，核实原文即可 · **检索** = 需系统找文献 · **新研究** = 可能要自己做
一个小实证（候选🟢支柱）。

## ⭐⭐⭐ 高优先（决定全书可信度）

### RT-06A · "由人来做才有价值"的领域是否真抗 AI？ 〔新研究 / 检索〕
**章节：** 第6章（出口的核心）。**关联 Q7。**
书的整个"还能往哪退"建立在"有些意义源抗 AI"。但目前几乎全是🟡推断。需要真实对照案例：
AI 进入某领域后，人类参与/价值**未减反增**（候选：AI 下棋后人类象棋的繁荣？AI art 后手工/
现场体验的溢价？现场音乐 vs 录制？）。**这可能是下一个独立的实证小研究**，像 SO 那样可证伪。
→ 不解决，第6章只能停在🟡，全书的"出口"就软。

### RT-07A · "制造 mattering 的制度"有真实经验证据吗？ 〔检索〕
**章节：** 第7章（建设型核心）。**关联 Q12。**
第7章现在全是🔴设计推演。需要：国民服务（AmeriCorps 等）、志愿体系、社区照护项目的
**意义/福祉产出**评估——这些"让人被需要"的制度，真的提升了参与者的意义感吗？
→ 不解决，第四部分（全书的"解药"）站不住，只是好听的设计。

### RT-02-LONG · 钱vs意义的长期/跨文化证据 〔检索 / 新研究〕
**章节：** 第2章（全书最强🟢支柱）。**关联 Q2/Q4。**
现有 UBI 实验都偏短（≤3年）、受 COVID/通胀污染、金额偏低。第2章结论虽稳，但若有人拿一个
"长期、充分金额"的反例就会松动。需：①系统再综合所有 UBI 实验的**心理/意义**（非财务）结果；
②挖 FIRE/提前退休社群的真实福祉轨迹（这是"有钱无工作"最接近的真实样本，且可能是自有🟢支柱）。

## 讨论用：我看到的全局格局

1. **全书最大的软肋在"出口"（第6、7章）**——诊断部分（1-4章）的🟢证据扎实，但"还能往哪退/
   怎么建"几乎全是🟡/🔴。**RT-06A 和 RT-07A 是把后半本书从"好听"变成"可信"的关键。**
2. **两个可能的"下一个自有🟢支柱"候选**：RT-06A（抗AI领域的真实对照）和 RT-02-LONG 里的
   FIRE 福祉研究。它们像 SO 研究一样，是你能独立做、可证伪、能当承重柱的小实证。
3. **大量是"核实"类**（RT-03A/04A/05A）——research_log 已抓到线索，只需逐篇读原文。这正是
   research_log 该喂给我们的，机制是通的，只是需要我们坐下来逐条核。
4. **诚实纪律的回报在这里兑现**：因为前4章只写了真有证据的，后4章诚实地停在证据边界并标了
   研究事项——这本书即使现在出，也不会有"把🔴当🟢"的硬伤；它会显得"诚实地未完成"，而非
   "自信地造假"。

**建议讨论顺序：** 先定 RT-06A 和 RT-07A 怎么做（它们决定后半本书）→ 再批量处理"核实"类
（RT-03A/04A/05A）→ 最后挑一个做下一个🟢支柱。
